Gender Classification Project

Proyek ini bertujuan untuk mengembangkan sistem berbasis Artificial Intelligence (AI) yang mampu mengenali gender dari wajah manusia secara otomatis. Proyek ini mengimplementasikan Computer Vision untuk membangun model klasifikasi wajah yang akurat dan efisien. Sistem ini memanfaatkan dataset CelebA dan menggunakan PyTorch sebagai framework utama untuk membangun model deep learning berbasis Convolutional Neural Networks (CNN).
